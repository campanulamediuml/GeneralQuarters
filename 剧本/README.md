# 1. 通用剧本参数

两个剧本均使用以下基础设置：

- 一回合 20 分钟，每天 72 回合；
- 每格 25 海里；
- A 阵营为美军，B 阵营为日军；
- 云层每 3 回合移动一次，风场每 6–12 回合缓慢变化一次；
- 除可部署潜艇外，每方另有 3 艘位置未知的随机巡逻潜艇。

## 1.1 结算原则

- 投送完成或航母全部损失均不提前结束对局。
- 通常在第 360 回合结算 VP；一方全军覆没时立即判另一方胜利。
- 投送目标按结算时仍存在的滩头物资计算，不按历史累计卸载量计算。清除滩头物资可同时恢复机场并降低对方投送 VP。
- VP 比值小于 1.25 为平分秋色，1.25–2 为战术胜利，大于 2 为战略胜利。
- 背负投送目标的一方必须完成全部投送目标，才可获得战略胜利；缺少任意一个目标时，最高为战术胜利。

## 1.2 雷达配置

马里亚纳剧本中：

- 美军除运输船外的所有舰船均装备对海搜索雷达和对空搜索雷达；
- 日军战列舰、战列巡洋舰装备对海搜索雷达和对空搜索雷达；
- 日军航母装备对空搜索雷达，大凤、信浓另有对海搜索雷达，龙凤没有雷达；
- 日军没有火控雷达。

珊瑚海按 1942 年各舰配置，不套用上述马里亚纳统一配置。

# 附录 A：胜利结算表

| 项目 | VP |
|---|---:|
| 击沉航母（CV/CVL/CVE） | 按该舰机库容量 |
| 航母丧失作战能力 | 机库容量的一半，保留 0.5 |
| 击沉战列舰／战列巡洋舰 | 6 |
| 击沉重巡洋舰 | 3 |
| 击沉轻巡洋舰 | 2 |
| 击沉驱逐舰 | 1 |
| 击沉运输船 | 1 |
| 每摧毁 1 个航空算子 | 0.25 |
| 剧本投送目标 | 珊瑚海 20；马里亚纳每个地点 40 |

航母丧失作战能力指满足以下任一条件：

- 飞行甲板摧毁；
- 结构损失**超过**初始生命值的 80%，刚好 80% 不算；
- 失去动力。

这一 VP 判定与通用舰船“重创”的“损失达到 80%”阈值不同，两者不互相替代。

- 航母先瘫痪后沉没只计一次，沉没后按整艘机库容量计分，不重复计算瘫痪分。
- 投送目标按结算时仍存在的滩头物资计算；完成由投送方得分，未达到由阻止方获得同等分值。
- 只有第 360 回合或一方全军覆没时结束对局，中途不因投送完成提前结算。
- VP 比值为高分除以低分：小于 1.25 平分秋色，1.25–2 战术胜利，大于 2 战略胜利。
- 背负投送目标的一方必须完成全部目标才可获得战略胜利，否则最高为战术胜利。
- 战果分对双方公开，得分明细逐条列出击沉、瘫痪、航空算子损失和投送目标。

General Quarters API

版本0.1.0 · 下载OpenAPI 3.0文档 · 返回游戏

约定

会话由创建或加入接口写入HttpOnly Cookie。所有错误均为{"error":"说明"}。hex使用ABCD坐标，AB为行、CD为列。客户端提交操作意图，服务器完成全部判定。

房间

方法路径用途
POST/api/v1/rooms创建房间，body可包含name、scenario_id
POST/api/v1/rooms/join凭token加入，body包含token、name
GET/api/v1/rooms/{id}/state获取当前玩家私有快照
GET/api/v1/rooms/{id}/events最近100条可见事件

命令与回合

POST /api/v1/rooms/{id}/commands
{"command_id":"唯一ID","base_version":1,"type":"SET_MOVE","unit_id":"a-flag","coord":"0203"}

POST /api/v1/rooms/{id}/ready
{"base_version":1,"ready":true}

CLEAR_MOVE使用相同结构但无需coord。所有当前玩家ready后统一结算。version变化后必须重新获取状态。

WebSocket

连接GET /ws，使用同一会话Cookie。消息仅用于通知客户端重新同步：

{"type":"player_joined|orders_updated|ready_changed|turn_resolved|presence_changed","version":2,"time":"..."}

AI扩展边界

后续DeepSeek适配器在服务器内运行。模型只接收当前阵营私有视图和对话，输出候选结构化命令；候选命令仍调用上述同一校验与回合引擎。API密钥不进入浏览器，自然语言不能直接改变游戏状态。
